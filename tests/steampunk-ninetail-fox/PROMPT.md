使用 Three.js r160+、OrbitControls 和 lil-gui 构建一个完整的、自包含的 HTML 应用，创建一个高度精细、带动画的 3D 蒸汽朋克九尾狐角色，并具备完整的游戏动作套件。

设计：
修长矫健的四足机械狐身、分层黄铜装甲片、外露发条骨架、颈部金属鬃毛、皮革项圈与挽具、黄铜铃铛与符牌，以及趾行四肢与分段利爪。头部为铰接式黄铜狐首，细长吻部可开合，双耳由扇形黄铜叶片构成，一双琥珀色玻璃眼，额心嵌有狐火晶石。胸腔是外露的狐火炉心，表面散布啮合齿轮、压力表、铜制液压管和发光的能量核心。背部有外露齿轮传动链与排气阀。肩、肘、髋、膝等关节处均有外露齿轮与液压活塞。臀部的齿轮毂上伸出九条分节机械尾，尾身覆盖层叠金属尾毛，尾尖各悬一盏发光狐火。

材质：
逼真的 PBR 黄铜、氧化铜、发蓝钢、锈蚀铁、裂纹皮革、金属尾毛、琥珀玻璃眼、狐火玻璃，以及带有完全程序化纹理和细节的金属磨损、锈迹、铜绿和皮革纹理。所有纹理必须通过 canvas 程序化生成，不使用任何外部图片或模型。

动画：
完整的游戏动作套件，包括待机呼吸、行走、奔跑、跳跃、落地、扑咬、爪击、九尾横扫、狐火投掷、受击、眩晕、嘲讽、嚎叫、施法、死亡，以及技能施放全套状态机。动作应基于骨骼关节旋转实时计算，支持平滑过渡、循环动作与非循环动作，非循环动作结束后自动回到待机（死亡可保持倒地）。九条尾巴应有独立、自然的跟随摆动。双眼应有微动和脉动发光，胸口炉心、额心晶石与尾尖狐火应随时间闪烁。

爆炸视图：
平滑的 0–1 滑块，沿径向或轴向（X/Y/Z）分离装备与骨骼组件，并带有青色引导线，从原始位置连接到分离后的位置。爆炸轴可在径向、X 轴、Y 轴、Z 轴之间切换。

GUI：
爆炸视图滑块、爆炸轴选择、动作状态切换（待机/行走/奔跑/跳跃/扑咬/爪击/九尾横扫/狐火投掷/受击/眩晕/嘲讽/嚎叫/施法/死亡）、动画速度（0.1×–5×）、齿轮转速（0.1×–5×）、线框模式、显示骨骼、自动旋转。

渲染：
响应式全屏 WebGL、ACES 色调映射、电影级工作室灯光（主光、补光、轮廓光、眼部与狐火点光源）、柔和阴影、基于 delta-time 的平滑动画、PMREM 程序化环境贴图、程序化雾效与地面。

技术要求：
完全以程序化方式生成所有几何体和纹理。不使用任何外部模型或图像资源。返回从 <!DOCTYPE html> 到 </html> 的完整、可执行 HTML，具有可正常使用的控件、干净的代码，无占位符，无 TODO。优先考虑视觉保真度、机械细节和性能。
